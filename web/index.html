Exact usageAST-derived symbol, import, and API evidence. Matching is case-insensitive and can include partial names; inspect each result.
StructuralStatic AST structure and source-line ordering within a scope. This does not prove runtime execution order.
EvolutionVersion retrieval and lineage over a controlled synthetic capability fixture.
The router uses predefined rules. Displayed route steps describe the selected pipeline, not an iterative reasoning trace. Router scores are fixed heuristic weights, not measured confidence.
BM25, global AST fusion, and adaptive fusion were evaluated and left out of the final dense pipeline. The optional reranker slightly improved validation but slightly reduced test NDCG, so dense fusion remains the default.
The evolution fixture is not historical APPS ground truth. This prototype retrieves existing code; generation is outside its scope.
